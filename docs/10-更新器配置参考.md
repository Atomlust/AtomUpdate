# 10 更新器配置参考

> `AtomUpdate.Updater`（标准更新器，04 §4）查阅型参考：配置五层、全部配置键、命令行参数、退出码、状态文件协议、平台目录。
> 更新器由 SDK 调度（`IAtomUpdater.InstallAndRestartAsync`），也可独立命令行调用。

## 1. 配置五层（后者覆盖前者）

| 层 | 来源 | 说明 |
|---|---|---|
| 1 | 内置默认 | 见 §2 各表"默认"列 |
| 2 | 安装目录 `updater.default.json` | 随客户端分发 |
| 3 | `--config <path>` | SDK 传入的任务/配置文件 |
| 4 | `ATOMUPDATE_UPDATER_CONFIG` 环境变量指向的文件 | |
| 5 | 命令行参数 | 最高优先 |

**例外：`verification` 节仅取第 1、2 层**（防同机攻击者经运行参数注入降级校验）。

## 2. 配置键（`UpdaterSettings`）

### 2.1 updater 节

| 键 | 默认 | 说明 |
|---|---|---|
| `logLevel` | `information` | trace/debug/information(=info)/warning(=warn)/error/critical(=error)/none（大小写不敏感） |
| `logPath` | null | 日志目录（null = 平台默认，见 §5） |
| `logRetentionDays` | 7 | 日志保留天数 |
| `globalMutex` | true | 按 appId 命名互斥；false 关闭（仅测试/调试） |
| `mutexTimeoutSeconds` | 0 | 互斥等待秒数（0 = 不等待，直接 0x1001） |
| `dryRun` | false | 只校验与演练，不替换/回传/重启 |

### 2.2 verification 节（仅前两层生效）

| 键 | 默认 | 说明 |
|---|---|---|
| `requireSignature` | false | true 后包未签名即失败（0x1004）。SHA256：提供 `--sha256` 即强制校验，**未提供则记 Warning 跳过哈希校验**（SDK 正常链路总会提供） |
| `publicKeys` | `{}` | 内置公钥集（keyId → PEM/SubjectPublicKeyInfo RSA 公钥），仅随客户端分发内嵌，不从 Api 动态获取 |

### 2.3 selfUpdate 节

| 键 | 默认 | 说明 |
|---|---|---|
| `enabled` | true | 自升级总开关 |
| `mode` | `dualProcess` | **保留键**：当前仅 dualProcess 一种实现，值不被读取分支 |
| `serverUrl` | null | **保留键**：自升级清单/下载实际用 `manifestUrl` 与任务配置，本键无消费方 |
| `checkBeforeInstall` | true | 安装前检查自升级；失败（断网/Api 不可达）记日志跳过，继续原任务 |
| `manifestUrl` | null | 自升级清单地址（`GET` 返回 `{version,url,sha256}`；空 = 跳过自升级检查） |

### 2.4 elevation 节

| 键 | 默认 | 说明 |
|---|---|---|
| `mode` | `onDemand` | onDemand / always / never |
| `retry` | `unlimited` | `unlimited`（或 ≤1）按**单次尝试**处理；数字 >1 时本进程内按其值重试提权。跨次授权循环由 SDK 负责（04 §4.10） |
| `allowExit` | true | 允许退出（用户拒绝提权时） |
| `skipIfNotNeeded` | true | 无需提权时跳过 |

### 2.5 install 节

| 键 | 默认 | 说明 |
|---|---|---|
| `strategy` | `merge` | merge（只覆盖包内文件）/ replace（另删包外文件，等价 merge + deleteOrphans） |
| `exclude` / `preserve` | `[]` | 排除 / 保留清单（glob） |
| `deleteOrphans` | false | 删除目标目录中包内不存在的文件 |
| `backupBeforeReplace` | true | 替换前备份 |
| `backupPath` | null | 备份目录（null = `backup/{appId}/{yyyyMMddHHmmss}/`） |
| `backupRetentionDays` | 3 | 备份保留天数 |
| `replaceRetryCount` / `replaceRetryDelayMs` | 3 / 250 | Windows 文件占用冲突重试，超出 → 0x1006 |
| `hooks` | `{}` | 阶段 → 命令映射（单个字符串或字符串数组）；6 个阶段：preInstall / postInstall / preReplace / postReplace / preRestart / postRestart（详见 04 §4.8） |
| `hookTimeoutSeconds` | 60 | 钩子超时 |
| `hookFailPolicy` | `abort` | abort（中断并回滚）/ continue |
| `installArgs` | null | exe/msi 安装参数兜底；优先级：任务顶层 `installArgs`（SDK 写包元数据值，`--install-args` 若给出则覆盖它）→ 本节。`silentArgs` 始终取包元数据 |

### 2.6 rollback 节

| 键 | 默认 | 说明 |
|---|---|---|
| `enabled` | true | 回滚总开关 |
| `onFailure` | true | 失败时自动回滚 |
| `keepBackupOnSuccess` | false | 成功后保留备份 |

### 2.7 restart 节

| 键 | 默认 | 说明 |
|---|---|---|
| `enabled` | true | 安装完成后重启主程序 |
| `args` | `--skip-update-check` | 重启参数（防更新循环，04 §5.2） |
| `delayMs` | 500 | 重启延迟 |
| `waitForExitMs` | 5000 | 等待主程序退出毫秒数（超时强制继续） |

### 2.8 report 节

| 键 | 默认 | 说明 |
|---|---|---|
| `enabled` | true | 安装结果回传（`POST /api/report/install`）；**false 时状态文件直接写 `reported=true`**（本次不由 SDK 补报） |
| `serverUrl` | null | null = 用任务配置中的 serverUrl |
| `timeoutSeconds` / `retryCount` | 15 / 3 | 回传超时与重试（指数退避） |
| `fallbackToLocal` | true | **保留键（更新器侧无消费方）**：回传失败时更新器一律写 `reported=false` 等 SDK 补报，本键不改变该行为，仅影响日志措辞 |

### 2.9 network 节

| 键 | 默认 | 说明 |
|---|---|---|
| `proxy` | null | 代理地址 |
| `timeoutSeconds` / `retryCount` | 30 / 3 | |

## 3. 命令行参数

`AtomUpdate.Updater --config <path> [选项]`；`--key value` 与 `--key=value` 双写法；未知参数报错（0x1002）。

| 参数 | 说明 |
|---|---|
| `--config <path>` | 任务/配置文件（SDK 经此传入；与节配置合并） |
| `--package <path>` ✅ | 更新包路径 |
| `--target <path>` ✅ | 目标目录 |
| `--to-version <v>` ✅ | 目标版本 |
| `--from-version <v>` | 当前版本 |
| `--package-type <t>` ✅ | zip/exe/msi/dmg/pkg/appimage/deb/rpm |
| `--install-mode <m>` | manual/onRestart/immediate |
| `--sha256 <hash>` | 期望 SHA256（提供即强制校验） |
| `--signature <sig>` `--key-id <id>` | 包签名与公钥标识（requireSignature 时校验） |
| `--restart <path>` / `--restart-args <args>` | 完成后重启的主程序与参数 |
| `--server-url <url>` | 回传服务器（report 为公开端点，无需密钥） |
| `--installation-id <id>` `--machine-fingerprint <fp>` `--app-id <id>` `--project-key <key>` | 状态隔离与回传标识 |
| `--install-args <args>` | 安装器附加参数 |
| `--replace-old <path>` / `--replace-pid <pid>` | 双进程自升级：替换旧更新器 / 等待指定进程退出 |
| `--log-level <l>` / `--log-path <dir>` | 日志级别与目录 |
| `--dry-run` | 只校验与演练 |
| `--no-restart` / `--no-rollback` | 关闭重启 / 关闭回滚 |
| `--verbose` | 等价 `--log-level debug` |
| `--elevated` | 标记当前已为提权进程 |
| `--help` | 帮助 |

## 4. 退出码

| 码 | 含义 |
|---|---|
| `0x0000` | 成功 |
| `0x1001` | 互斥获取失败 |
| `0x1002` | 参数错误 |
| `0x1003` | 提权被拒绝 |
| `0x1004` | 校验失败 |
| `0x1005` | 备份失败 |
| `0x1006` | 替换失败 |
| `0x1007` | 安装器失败 |
| `0x1008` | 钩子失败 |
| `0x1009` | 回滚失败 |
| `0x100A` | 重启失败 |
| `0x100B` | 未知错误 |

## 5. 状态文件协议

路径：`{stateRoot}/{appId}/updater-state.json`（stateRoot 见 §6）。SDK 启动时读取未回传状态（`reported=false`）补报。

| 字段 | 说明 |
|---|---|
| `installationId` / `machineFingerprint` / `projectKey` / `appId` | 回传标识 |
| `fromVersion` / `toVersion` | 版本迁移 |
| `stage` | starting / verifying / installing / completed / failed / rolledBack |
| `result` | success / failed / rolledBack（终态前为 null） |
| `reason` / `installMode` | 原因 / 安装模式 |
| `elevated` / `elevationRejected` | 提权状态 |
| `errorCode` / `errorMessage` / `logPath` | 十六进制错误码（如 `"0x1004"`）/ 详情 / 日志路径 |
| `timestamp` / `retryCount` | 更新时间 / 已重试次数 |
| `reported` | 回传是否已送达；false 等 SDK 补报 |
| `updaterVersion` | 写入方更新器版本（自升级替换后可识别旧版本写入的状态） |

## 6. 平台目录

| 用途 | Windows | macOS | Linux |
|---|---|---|---|
| AtomUpdate 根（state/backup 的父级） | `%LocalAppData%\AtomUpdate` | `~/Library/Application Support/AtomUpdate` | `~/.config/AtomUpdate` |
| 更新器日志根 | `%LocalAppData%\AtomUpdate\logs\updater` | `~/Library/Logs/AtomUpdate/updater` | `~/.local/share/AtomUpdate/logs/updater` |
| 默认备份 | `{根}\backup\{appId}\{yyyyMMddHHmmss}\` | 同根派生 | 同根派生 |

路径契约与 SDK 侧 `PlatformPaths` 一致：`state/{appId}/` 与 SDK 补报读取同一位置。
